Features

  • Save list with metadata — game version, last played, size, backup count.
  • Manual backups — ZIP or 1:1 folder copy, with optional labels.
  • Auto-backup before launch — only when the save changed; configurable retention.
  • Atomic restore — optional safety backup of the current save first.
  • Three launcher modes — from the app, desktop shortcut, or Steam Launch Options.
  • Steam-friendly progress window — shows backup status, with a skip button.
